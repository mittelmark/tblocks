# 1. LLM Traps :: & Risks

## 1.1 Privacy & Data Leakage
Feeding real patient or proprietary data
into public APIs breaches confidentiality.

## 1.2 Foreign Code Injection
Licensing issues arising from generated code,
requires strict auditing of output.

## 1.3 Dependency Injection
AI models frequently introduce unnecessary libraries,
complicating simple statistical pipelines.

## 1.4 Non-Deterministic Behavior
The exact same input prompt may yield varying
statistical methodologies or code structures.

## 1.5 Hallucinations
Models confidently fabricating mathematical
justifications or phantom functions.
